# School website images

Place school-approved photos in this folder and commit them to GitHub.

- `home.png` — main homepage hero image (recommended landscape 1600×1000 or larger)
- `about.png` — About section school/uniform photo (recommended 1200×900)
- `staff/` — optional staff portraits, e.g. `staff/headteacher.jpg`
- `milestones/` — optional achievement photos, e.g. `milestones/top-student-2026.jpg`

Images are served publicly at `https://matoranhembe-high-school.onrender.com/images/home.png`, etc. Keep file names lowercase and match extensions exactly. Git doesn't track empty directories; create the `staff` and `milestones` folders when adding pictures.

The Staff and Milestones admin forms currently require full HTTPS image URLs. For images committed here, use the full live URL, e.g. `https://matoranhembe-high-school.onrender.com/images/staff/headteacher.jpg`.

Only publish photos you have permission to use. For identifiable students, obtain appropriate guardian and school consent before publishing. Avoid storing sensitive student information in image filenames or metadata.

This is a GitHub-based static image workflow, not an admin upload feature. Images must be added to the repository to persist across Render deployments.
